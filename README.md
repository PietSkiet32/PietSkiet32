### iOS apps

- **[Golf Analytics by DataTee](https://apps.apple.com/za/app/golf-analytics-by-datatee/id6756515315)**: records every shot of a golf round so golfers can analyse their game. React Native, Expo and Appwrite.
- **[WoordSpel](https://apps.apple.com/za/app/woordspel/id6744609816)**: a daily Afrikaans word game, built so Afrikaans speakers have one in their own language. Expo, Appwrite and RevenueCat.
- **I Don't Eat That** (in App Review): a family meal planner that suggests dinners everyone will eat, with an AI recipe chat and voice input. Expo, Supabase, Claude Haiku 4.5, Deepgram and RevenueCat.
- **Plate to Pillow** (due for App Review): finds which eating habits go with bad nights, from meal photos and a morning sleep check-in. Expo, Supabase and Gemini.

Every App Review rejection became a preflight check that each new app runs.
